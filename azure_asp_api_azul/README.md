# template-repository
Este repositorio se puede utilizar como template para proyectos Java. Contiene todo el esqueleto necesario para el repositorio

# Estructura 

Tiene los directorios típicos básicos para un proyecto Java


# Archivos Incluídos

El template viene con algunos archivos frecuentemente utilizados. El contenido de estos archivos
se ha configurado de manera genérica con los valores más comunes. 

**Importante:**
Es indispensable revisar cada uno de los archivos incluídos y actualizar el contenido
para adaptarlo a las necesidades del proyecto.

## .gitignore

El archivo .gitignore está configurado para excluir de los commits los archivos y directorios que comunmente
se excluyen en los proyectos java. Se incluyeron secciones que corresponden al uso de IDEs en específico.

**Importante:**
Es indispensable revisar el .gitignore y actualizar el contenido para adaptarlo a las necesidades del proyecto.

## CODEOWNERS

Se debe reconfigurar y especificar quién será el responsable de revisar cada una de las diferentes tecnologías
y paths del proyecto. La versión incluída en este repositorio tiene un valor genérico apuntando al grupo
aspintegraopciones/revisores

**Importante:**
Es indispensable revisar el CODEOWNERS y actualizar el contenido para adaptarlo a las necesidades del proyecto.

## pom.xml
Se incluye un archivo pom.xml con algunas especificaciones genéricas para un proyecto maven con spring-boot pero 
de ninguna manera se puede considerar que el pom esté listo para usarse.

**Importante:**
Es indispensable actualizar los tags con la información específica del proyecto, del artefacto y de la versión además de agregar todas las librerías y dependencias que se estarán utilizando en el proyecto.

# README.md

Este archivo. Asegúrate de que el README describa correctamente y de manera completa los detalles de tu proyecto, instrucciones para hacer el build y el despliegue así como configuraciones y variables de ambiente requeridas.
