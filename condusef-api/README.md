# CONDUSEF

Implementación de las API de REDECO y REUNE de la CONDUSEF.

## Run Locally

Clone the project

```bash
  git clone https://gitlab.integraopciones.mx/qa/condusef-api.git
```

Go to the project directory

```bash
  cd condusef-api
```

Install dependencies

```bash
  go mod tidy
```

Start the server

```bash
  go run server.go
```
